### 2.3 版本与签名

- `versionName` 固定两段 `<主>.<次>`，发版只改这一行；
- `versionCode = 主 × 100 + 次`，例如 `1.0 → 100`、`1.3 → 103`；
- release 签名从 `android/keystore.properties` 读取，`jks` 与属性文件均不入库；
- 未配置签名时 `assembleRelease` 产出未签名 APK，仅用于本地验证。

`keystore.properties` 示例（不要提交）：

```properties
storeFile=keystore/fieldnotes.jks
storePassword=******
keyAlias=fieldnotes
keyPassword=******
```

## 6. 常见问题与规避

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| `Unsupported class file major version` | JDK 版本不对 | `JAVA_HOME` 指向 JDK 17 |
| Kotlin 插件冲突 | AGP 9 已内置 Kotlin | 不再应用 `org.jetbrains.kotlin.android` |
| KSP 与 Kotlin 版本不匹配 | 版本未对齐 | 使用 `2.3.12`，与 AGP 9.4.1 配套 |
| Room 编译报 schema 目录缺失 | 未配置 `ksp { arg("room.schemaLocation", ...) }` | 加入 schema 导出目录并入库 |
| 中文乱码 | 源文件 / Gradle 编码不一致 | `-Dfile.encoding=UTF-8`；文件存 UTF-8 |
| `Foreign key constraint failed` | 删除顺序 / 未开外键 | 使用 `withTransaction`；Room 自动开 FK |
| 弹层被键盘遮挡 | 未处理 IME | `Modifier.imePadding()` + `adjustResize` |
| 红点与进度不一致 | 两处各自计算 | 统一由 `PlanSummary` 派生 |
| 导入后条目重复 | 未使用 nameKey / 唯一索引 | Repository 预去重 + DB 唯一索引兜底 |
| SAF 读不到文件 | Uri 权限未持久化 | 仅单次读取，不缓存 Uri；必要时 `takePersistableUriPermission` |
| release 安装失败 | versionCode 未递增 | 由 versionName 自动推导，发版只改版本名 |

## 7. 代码规范

- Kotlin 官方风格；4 空格缩进；文件名 = 主类名；
- Compose 函数 PascalCase，`@Composable` 不返回 Unit 以外的值；
- ViewModel 暴露 `StateFlow<UiState>` 与 `suspend fun` / 事件方法，不暴露可变集合；
- Repository 的写方法全部 `suspend` 且在事务内；
- 字符串资源放 `strings.xml`（v1 中文），代码不硬编码用户可见文案；
- 颜色 / 字号 / 圆角统一走 `Tokens`，不在 Composable 内散落十六进制；
- 每个 DAO 查询写明排序；每个事务写明边界；
- 不留 `TODO()` 在 release 路径；临时开关用 `BuildConfig.DEBUG`。


发布前必须做一次**换机往返**：

1. 设备 A 建 6 分类 / 26 物品 / 4 模板 / 3 计划，勾选部分条目；
2. 导出 JSON 与 gzip 各一份；
3. 清除应用数据（或卸载重装）；
4. 导入 JSON → 合并，核对四类数据、勾选态、红点；
5. 再导入同一文件 → 合并，确认全部跳过、无重复；
6. 清空后导入 gzip → 覆盖，确认完全恢复。
