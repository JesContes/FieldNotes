# 寸笺 · 安全与敏感信息审计

| 项目 | 内容 |
| --- | --- |
| 审计对象 | `com.fieldnotes` 1.0 release APK + 源码 + 仓库暂存区 |
| 审计时间 | 2026-10-26 |
| 结论 | **未发现需要阻断发布的高危问题**；本地密钥未入库，APK 无网络权限 |
| 证据 | `aapt2 dump badging/permissions`、`apksigner verify`、`git ls-files` / `git grep --cached`、源码检索 |

---

## 1. 敏感信息

| 检查项 | 结果 | 处理 |
| --- | --- | --- |
| 签名密钥 `fieldnotes.jks` | 存在本机，**未入库** | `.gitignore` 排除 `android/keystore/`、`*.jks` |
| `keystore.properties` | 存在本机（含本地口令），**未入库** | `.gitignore` 排除 |
| `local.properties`（本机 SDK 路径） | **未入库** | `.gitignore` 排除 |
| `.dsh-analysis/`（会话记录，约 8 MB） | **未入库** | `.gitignore` 新增排除 |
| 构建产物 / 截图 / APK | **未入库** | `android/build/`、`android/app/build/`、`android/captures/`、`*.apk` |
| 源码硬编码密钥 / token / 密码 | 未发现 | 全量 `git grep --cached` 检索 |
| 文档中的真实口令 | 未写入 | 仅描述“本地 keystore 路径”，不写口令 |

> 暂存区实测：`git ls-files` 中无 `keystore`、`local.properties`、`.dsh-analysis`、`*.apk`、`build/`、`captures/`；源码内无硬编码密钥。

## 2. 权限与组件暴露

`aapt2 dump badging` / 合并后 Manifest 结果：

| 项 | 实际值 | 评估 |
| --- | --- | --- |
| `INTERNET` | **未声明** | 纯本地，符合需求 9 |
| 存储 / 定位 / 相机权限 | 未声明 | 导入导出走 SAF |
| `uses-permission` | 仅 `com.fieldnotes.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` | AndroidX 生成的签名级内部权限 |
| `allowBackup` | `false` | 禁止 adb / 云备份带走数据库 |
| `usesCleartextTraffic` | `false` | 无明文流量 |
| `debuggable` | release 未开启 | `aapt2 badging` 无 application-debuggable |
| 导出组件 | 仅 `MainActivity`（LAUNCHER），不解析外部 Intent 参数 | 无可利用入口 |
| 其它组件 | `InitializationProvider` / Room service `exported=false`；`ProfileInstallReceiver` `exported=true` 但受 `android.permission.DUMP` 保护 | AndroidX 标准组件，风险可接受 |

## 3. 代码层高危 API

全量检索 `execSQL`、`RawQuery`、`WebView`、`setJavaScriptEnabled`、`Runtime.exec`、`ProcessBuilder`、`Class.forName`、`File(`、`openFileOutput`、`http://`、`https://`：

- **未发现**原始 SQL 拼接（Room 全部使用参数化 `@Query`）；
- **未发现** WebView、动态代码加载、外部进程执行；
- **未发现**自行拼接文件路径（文件只经 SAF `Uri` 读写）；
- 唯一的 `http://` 匹配来自 XML 命名空间声明，不是网络请求。

## 4. 导入安全边界

`ExportCodec` 为唯一的外部数据入口，已实施：

| 防护 | 实现 |
| --- | --- |
| 文件大小 | 32 MB 上限（读取前查 `OpenableColumns.SIZE`，读取中累计） |
| gzip 炸弹 | 解压后 128 MB 上限，流式计数 |
| 格式 / 版本 | `format` 必须匹配；`version > 1` 拒绝 |
| 数量上限 | 分类 1,000 / 物品 10,000 / 模板 5,000 / 计划 5,000 / 单容器条目 100,000 |
| 字段长度 | 名称、备注、说明、目的地按设计上限截断 |
| 日期 | 1900–2200，返程 ≥ 出发 |
| 颜色 | 仅接受 `#RRGGBB`，否则回退默认色 |
| 类型异常 | 单条跳过并计数，不执行外部内容 |
| 数据库写入 | 单事务，失败整体回滚 |

本轮审计补上了此前缺失的**数量上限**，并新增单元测试 `rejectsOversizedCategoryArray`。

## 5. 数据与隐私

- 数据库位于应用私有目录 `/data/data/com.fieldnotes/databases/`，依赖 Android 应用沙箱隔离；
- 不申请网络权限，不集成统计 / 崩溃上报 / 广告 SDK；
- 导出文件为**用户主动**通过 SAF 生成，内容为用户自己的分类、物品、模板与计划；
- `allowBackup=false`，卸载即删除应用数据；
- 未做 SQLCipher 加密：这是本地低敏感数据应用的有意取舍；若后续提高隐私等级，可在 Repository 层引入加密库。

## 6. 签名与产物

```text
package: com.fieldnotes
versionCode=100 versionName=1.0
minSdk=26 targetSdk=36
V2 Signer: CN=Field Notes, ...
```

- `apksigner verify` 通过（V2 签名）；
- APK 无 `INTERNET` 权限；
- 签名密钥与口令仅存在本机，不随仓库分发。

## 7. 残留风险与建议

| 风险 | 等级 | 建议 |
| --- | --- | --- |
| 本地 SQLite 未加密 | 低 | 设备已被 root / 调试时可能被读取；如需要可加 SQLCipher |
| 导出文件为明文 | 低 | 用户主动导出，建议用户自行保管；后续可加口令加密 |
| `ProfileInstallReceiver` 导出 | 低 | 受系统 `DUMP` 权限保护；如追求最小暴露可在 Manifest 移除 |
| 本地 keystore 口令较弱 | 低 | 仅本机使用；正式上架前更换强口令并妥善备份 |
| SAF 异常分支未全部自动化 | 低 | 后续并入 `tools/ui` 场景或 instrumented test |

## 8. 审计结论

- 未发现硬编码密钥、网络权限、WebView/动态执行、SQL 拼接等高危问题；
- 导入路径已具备文件大小、解压上限、数量上限、格式/版本与事务回滚防护；
- 仓库暂存区不含签名密钥、本机配置或会话记录；
- **可以推送并打 1.0 标签**。
